`add_multilabel()` attaches an annotation table below a chart - `+`/`-` rows, symbols, or plain
text aligned to each x category, with optional sample-size and category-label rows and grouped
spans.

<Example name="multilabel" alt="Strip plot with a plus/minus multilabel table below" />

`showSampleSize=True` injects a per-category count row, and `categoryLabel=True` renders the
category names as an angled row of the table:

<Example name="multilabel_sample_size" alt="Strip plot with sample size and category-label rows" />

Use `style="symbol"` for filled/open dots, and `span=` to bracket groups of categories under a
shared label:

<Example name="multilabel_symbol" alt="Strip plot with a symbol multilabel table and grouped spans" />

## Rotating row values

A row of numbers - doses, timepoints, concentrations - is usually far wider than its band. Stand
it on end with `rowValueAngle`, in degrees: `-90` reads bottom-to-top, `90` reads top-to-bottom.
Values rotate about their own center, so they stay centered on their category, and the row grows
to fit its tallest rotated value.

Give a row a **list** of angles, one per category, to rotate only some of its cells. That is what
keeps the untreated controls' `-` placeholders upright below, while the doses turn:

<Example name="multilabel_rotated" alt="Dose response strip plot with the dose row standing on end" />

All four shapes:

```python
rowValueAngle=-90                              # every row
rowValueAngle={"dose (µM)": -90}               # one row, by label
rowValueAngle=[0, -90]                         # one per row, in display order
rowValueAngle={"dose (µM)": [0, 0, -90, -90]}  # one per cell of that row
```

Rotation applies in every row style, so a `"symbol"` row's marks turn as readily as a text row's
characters - though the default `"circle"` looks the same at any angle, so pair it with a shape
that has an orientation, such as `symbol="triangle-up"`.

Rows are 10 px tall by default and rotated rows auto-size. Pin them with `rowHeight`, which takes a
single height, a dict keyed by row label, or a list in row-display order:

```python
rowHeight=14                          # every row
rowHeight={"dose (µM)": 26}           # one row; the rest auto-size
```

:::note
A lone `-` in a text row renders as a typographic minus (`−`), matching what a `plusminus` row
draws for `False`, so placeholder rows line up with `+`/`−` rows above them.
:::
